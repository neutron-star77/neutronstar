# 项目简介

这是你正在浏览的站点本身。一个轻量、可维护的静态博客引擎。

## 特性

- 内容集合驱动的文章 / 日记 / 项目
- 标签聚合与标签云
- 文章目录（TOC）侧栏
- 首页 Three.js 星场（克制使用）
- RSS 订阅
- 一键部署 Cloudflare Pages

## 技术栈

Astro 7 · Tailwind v4 · Three.js（仅装饰）· Cloudflare Pages
